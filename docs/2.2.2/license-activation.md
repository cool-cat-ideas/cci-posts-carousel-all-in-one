# Activate Pro

The base plugin creates and publishes normal carousels without a Pro license.
Activate Pro when the site needs current WooCommerce prices, sale states,
ratings and buying actions, Commerce Luxe, Story Commerce, Video Showcase,
Elementor, analytics, autoplay indicators or Multisite.

## Activation

1. Install and activate the base plugin.
2. Install and activate CCI Posts Carousel All In One Pro of the same release line.
3. Open **CCI Posts Carousel All In One > Dashboard**. Find the **CCI Posts Carousel All In One Pro** license card in the plugin sidebar.
4. Paste the license key and choose **Activate**.
5. Return to the carousel editor and select the required Pro feature.

The key is exchanged for local activation state; normal frontend rendering
does not make a remote license request for every carousel view.

## Staging and domain changes

Activate the production domain and the staging domain according to the site
limits of the purchased plan. Before changing the canonical WordPress URL,
deactivate the old domain when it is still accessible, update `home` and
`siteurl`, then activate the new domain.

## If activation fails

Check that:

- the base plugin and a compatible Pro package are both active; their version numbers do not need to match,
- WordPress can make outbound HTTPS requests,
- the WordPress Home URL is correct,
- the plan still has a free site activation,
- server time and SSL validation are correct.

If you would like us to check the error, open
[Services and support](https://coolcatideas.com/en/account/services/) in your
Cool Cat Ideas purchase account. Under **Contact the team**, choose **General
question** for an activation question, or **Technical support for a licence**
when available. Include the displayed error code and domain, then click
**Send message**. You can follow our reply under **Your conversations**.

Please do not paste the full license key into the message or a screenshot.
