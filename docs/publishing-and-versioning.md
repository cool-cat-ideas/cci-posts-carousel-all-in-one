# Installable packages and source code

For an existing WordPress site, use the installable ZIP from the
[product page](https://coolcatideas.com/products/cci-posts-carousel-all-in-one/)
or the WordPress.org plugin directory. The base plugin is installed in
`wp-content/plugins/cci-posts-carousel/`.

GitHub provides the source repository and contribution history. GitHub's
Source code archives are repository snapshots, with documentation, tests and
build files. They are different from a prepared WordPress installation ZIP.
See [Build from source](./building-from-source.md) when changing the code.

## What an installation contains

The package includes plugin PHP, compiled JavaScript and CSS, bundled runtime
libraries, translations, WordPress `readme.txt`, installation instructions,
licenses and third-party attribution. Repository documentation and
`.wordpress-org/` listing screenshots are separate source assets.

The screenshots demonstrate real demo configurations. Captions identify
features requiring Pro and separately installed extensions.

## Update an existing site

Use [Installation and updates](./2.2.2/installation.md) to replace the base
plugin in place and keep saved 2.x carousels. The base plugin and Pro have
separate version numbers and update channels. Check the version of each
installed plugin under **Plugins > Installed Plugins**.

Read [CHANGELOG.md](../CHANGELOG.md) or the WordPress readme changelog for
version-specific changes. Older source guides remain available in their
versioned folders.
