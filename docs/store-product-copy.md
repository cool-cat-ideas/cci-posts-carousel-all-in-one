# WP Posts Carousel product copy reference

This file is a copywriting reference for store products. It is not a substitute
for the technical documentation in `docs/{version}`.

## Core product

Product name:

```text
WP Posts Carousel All In One
```

Short description:

```text
Create a carousel from posts, pages, products or manual slides, then reuse it with Gutenberg or a shortcode.
```

Long description:

```text
Choose the content, arrange manual slides when needed and check the result in
the visual editor. A saved carousel can appear in several places, so one change
updates every page that uses it. The base plugin includes templates, filters,
custom field mapping and Owl Carousel or Swiper/React rendering. Choose Pro
when you need current WooCommerce prices and buying actions, Commerce Luxe,
Story Commerce, Video Showcase, Elementor, reports or Multisite tools.
```

## Included without a license

- Saved carousel definitions.
- Shortcode publishing.
- Gutenberg block with saved-carousel selector.
- Posts, pages and custom post type sources.
- Taxonomy filtering and ordering.
- Manual slide selection and custom slides.
- Two selectable frontend engines: Owl Carousel and Swiper/React.
- Server-rendered output with interactive frontend behavior.
- Templates: `default`, `simple`, `light`.
- Built-in ordering from WordPress Popular Posts statistics.
- Frontend taxonomy filters.
- Custom field mapping.
- Image performance settings.
- Diagnostics and plugin feed.

## Pro includes

- Premium features activated by a site license.
- Elementor widget with saved-carousel selector.
- Pro analytics for views and clicks.
- A progress bar, seconds countdown or both before autoplay moves to the next slide.
- Advanced WooCommerce merchandising.
- Commerce Luxe, Story Commerce and Video Showcase templates.
- Every commercial WPC feature in one plugin and one license.
- Per-site Multisite initialization and copying definitions between licensed network sites.

## Support

Public questions and bug reports belong in the product repository under
https://github.com/orgs/cool-cat-ideas/repositories. This channel has no
guaranteed response time. Paid support is bought on the product page; the
private request and further messages are then handled in the Cool Cat Ideas
customer panel.

WordPress Popular Posts support is built into the base plugin. It is not a
separate CCI product or download.

## Copy rules

- Do not claim features that are not implemented.
- Do not call a template a theme.
- Describe Commerce Luxe, Story Commerce, Video Showcase and WooCommerce Products as built-in Pro features, never separate installable products.
- Use `Template` for template add-ons and `Integration` for source/data add-ons.
- Installation and support services are checkout services, not plugin
  extensions.
- Write for a site owner, not a developer. Start with the task and use short
  sentences.
- Keep `Free` for an edition badge or download button. Do not add it to a
  product title or normal paragraph.
